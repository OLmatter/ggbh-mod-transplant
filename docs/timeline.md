# 调试时间线（完整复盘）

> 一天半的完整调试历程。每个「卡死」都标注了根因和当时的现象，供后来者对号入座。
> 时间为本地时间 2026-08-17 ~ 08-18。

## 阶段〇：事故背景

- 上午：为自动关弹窗写了 `CtorPatch`（hook `MapWorldMgr` **构造函数**捕获实例）→ 全部存档进档瞬间卡死
- 二分法定位：禁用 CtorPatch 后恢复正常；CustomLogPatch（实例方法钩子）无辜
- **教训固化：绝不 hook Il2Cpp 构造函数**

## 阶段一：生涯大事导出为空（3 轮）

1. `export` 读 `g.world.unitLog.allAddLogData` → 2 号档里钟青曼 3970 年历史一条没有
2. 反射逆向（ReflectionOnly）发现持久层：`DataMgr.dataUnitLog.data.allLog[unitID]`
   - `DataMgr` 无静态单例 → 运行时探测 `typeof(g)` 静态属性（后证实是 `g.data`）
3. 新版 export 读持久层 → 渲染成功（68 故事 + 74 大事）但 JSON 是 `null`
   - 根因：序列化器 `SkipTypes` 含 "Il2CppSystem"，`List<T>` 全名以此开头被整体跳过
   - 修复：**容器先枚举再跳过检查**（顺带修好了法宝/道具导出，单位 JSON 从 9KB 涨到 108KB）

## 阶段二：注入崩溃（3 轮）

1. 直接 `BuildFrom(JSON)→UnitInfoData` + `AddUnit` → 原生 IndexOutOfRangeException + 幽灵单位（计数+1、查无此 ID）
2. 一度误判为「世界结构性字段越界」→ 工厂骨架方案（`RandomInitNPCUnit` 造本世界合法骨架 + `MergeInto` 递归合并）→ **注入不崩了**
3. 但数据全没写进去（名字还是随机 NPC）→ 诊断输出 `JSON键=1` → **真正的根因浮出水面**：

### SkipWs 吞逗号（本项目的世纪 bug）

自研 JSON 解析器的跳空白函数：

```csharp
while (... || s[pos] == ',') pos++;   // ← 逗号被当空白吞了！
```

每个对象解析完第一对 `key:value` 后逗号被吞 → 既非 ',' 又非 '}' → break。**每个对象只有第一个键**。它伪装了三种症状：空单位越界崩溃、数据合并无效、日志只进 1 条。

定位方法：提取解析器到本地 harness（纯 .NET exe），对真实导出文件跑 → `keys=1` 复现 → 逐轮跟踪打印 → 锁定 pos=31（第一个逗号后）。修复后 4892 个键值对全解析。

**如果一开始就「先验解析器再怪游戏」，这个 bug 5 分钟就能找到。**

## 阶段四：UI 显示为空 → 两级存储真相

- 人物故事 UI 为空 → 诊断：持久层 `allLog` 974 个单位里没有她
- 发现：日志走的是**会话缓冲**，合并只在过月/存档时发生，**UI 只读持久层**
- 尝试 1：调游戏自己的 `WriteLogData` 强制合并 → 反射显示签名 `Int32[]` 是垃圾数据，Invoke 绑定失败
  - 教训：**互操作签名以编译器为准**（写 sig_check.cs 运行时加载验证 → 实际全是标量）
- 尝试 2：`MerageAddLog` 直入 → 需要构造 `WorldUnitLogMgr.LogData` 包装类 → `new` 报 CS1729、`Activator.CreateInstance` **抛异常而不是返回 null**（`??` 兜底永远不触发）
- 尝试 3（成功）：单条入缓冲 → `UpdateLogData()`（缓冲→当月暂存，之前缺的环节！）→ `WriteLogData(该条月份)` → 清缓冲

## 阶段五：月份盖章

- 存档读档后全部生涯大事显示 1537 年
- 机制：**合并路径用当前月重写条目月份**。自然游戏里日志当月产生当月合并所以无害；移植历史日志=日期全灭
- 且之前「验证月份正确」是被惰性视图骗了——视图还指着内存里未盖章的对象，读档后从 raw 重建才露馅
- 尝试：直写持久层 raw → 发现 raw 是 `List<Il2CppStringArray>`，条目=2 元素 `[月份, "月&id&参数"]`（安全检查救了一命：结构非 1 元素即中止）
- **终版 fixmonths**：自验证 raw[0][0] 是接近当前月的整数 → 用文件条目（真实月份）`DataToString()` 重建 raw → 视图强制重建 → 第 9 年被击杀、第 669 年成婚全部恢复

## 阶段六：存档卡死

- fixmonths 后跑了 `addvital`（内含合并调用）→ 用户存档卡死 + 日期又被盖回
- 结论：**合并 API 会重序列化该单位全部数据**——修完 raw 后不能再碰任何合并
- 最终流程：fixmonths（不跑 addvital）→ 存档 → 成功（20:00，文件正常写入）

## 遗留事项

- 穿越叙事因「不能碰合并」暂缺，可用 raw 直写方式补（格式：`["18441", "18441&Q999999&A文本&A&"]`）
- ReflectionOnly 反射在本项目多次给出误导信息（类型枚举空、签名错误）——**结论一律以编译器/运行时为准**
- `MerageAddLog` 的包装类构造（`il2cpp_object_new` + `ctor(IntPtr)`）未走通，值得再研究
